
# Hotel Booking System

## Project Overview
The Hotel Booking System is a C# Windows Forms desktop application that allows customers to search for available hotel rooms and manage reservations.

## Main Features
- Search for rooms by check-in date, check-out date, and number of guests.
- View room types, prices, capacity, and amenities.
- Create, view, and cancel reservations.
- Prevent overlapping room bookings.
- Provide an administrator dashboard for managing rooms and reservations.

## Technologies
- C#
- Windows Forms
- MySQL
- Visual Studio Community
